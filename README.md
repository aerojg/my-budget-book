# 나의 가계부 만들기 (my-budget-book)

시니어도 쉽게 쓸 수 있는 가계 소비 지출 자동정리 프로그램을 AI와 함께 만드는 프로젝트입니다.

## 만드는 순서
1. 1단계: 가계 지출 정리 (직접 입력, 엑셀/CSV 업로드, 영수증 사진 인식)
2. 2단계: 수입·지출 항목별 가계부 정리
3. 3단계: 가계수지 분석과 지출 개선방향 제시

## 특징
- 광고와 금융상품 추천이 없는 순수 지출 관리 도구
- 큰 글씨와 단순한 화면
- 개발 과정을 유튜브와 블로그로 공개

## 개발 도구
Python, Streamlit

## 진행 상황
1단계 직접 입력 화면 구현 중
